AuraTranslate

设置

分别配置 YouTube / Google Drive 实时字幕翻译和普通网页沉浸式翻译使用的 LLM API。

YouTube / Google Drive

实时字幕翻译 API

用于 YouTube 和 Google Drive 字幕抓取、预翻译及视频上的双语字幕叠加层。

Webpage

沉浸式翻译 API

用于普通网页右侧小圆球触发的中英对照翻译。

默认沿用实时字幕 API；选择 OpenAI-compatible API 后可单独配置沉浸式翻译调用的 API。

免 Key 接口没有官方稳定性保证，可能限流、不可访问或失效。官方接口的兜底请求可能产生额外费用；主 API 超时也可能已经计费。两种方式都会缓存成功译文，失败时保留已完成内容。切换兜底不会清除已有译文。

General

通用设置

控制语言、LLM 智能断句、专业术语、字幕大小、ASR 纠错和字幕开关。
