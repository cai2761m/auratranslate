# AuraTranslate

**使用自己的翻译 API，看双语视频字幕，读中英对照网页。**

AuraTranslate 是一个基于 Manifest V3 的浏览器扩展：将 YouTube 英文字幕和 Google Drive 视频转写稿翻译为中文，也能在网页原文下方插入译文。支持简体中文和繁体中文，使用 OpenAI-compatible Chat Completions API。

扩展依赖视频已有的字幕或转写稿，不录制音频，也不能为没有字幕的视频进行语音转写。

## 功能

- **视频双语字幕**：同时显示英文和中文，支持拖动字幕位置、调整字号。
- **渐进字幕翻译**：优先处理当前播放位置附近的字幕，按需准备和翻译后续片段。
- **省 token 模式**：默认翻译当前位置及未来 2 分钟，可选预翻译 1、2、3 分钟，也可切换为整部视频翻译。
- **句子级处理**：可开启 LLM 智能断句、自动字幕纠错，以及专业术语原文显示。
- **沉浸式网页翻译**：为正文标题、段落、列表、提示框和页内目录添加译文，保留原文供对照阅读。
- **行内格式保留**：新网页译文保留常见的行内代码、强调、链接和换行；模型返回的格式不可用时回退为纯文本。
- **独立 API 配置**：字幕与网页翻译可分别使用不同接口，也可共用字幕 API。
- **本地翻译缓存**：刷新页面或后台重启后复用已有字幕和网页译文；网页先显示缓存命中的内容，再请求缺失文本。

## 快速开始

### 1. 从源码安装

克隆仓库，或下载并解压仓库 ZIP：

```sh
git clone https://github.com/cai2761m/auratranslate.git
```

在 Chrome 中：

1. 打开 `chrome://extensions`。
2. 开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的 `auratranslate` 文件夹。
4. 从扩展菜单打开 AuraTranslate，点击 **设置**。

加载扩展不需要构建，也不需要安装 npm 依赖；Node.js 依赖仅用于开发测试。

### 2. 配置 API

在 **实时字幕翻译 API** 中填写：

| 设置项 | 填写内容 |
| --- | --- |
| 翻译服务 | **OpenAI-compatible API**，当前设置界面唯一的服务类型 |
| API Key | 服务商提供的 API 密钥 |
| Base URL | 服务商的 Chat Completions 基础地址，按接口要求包含版本路径 |
| 模型 | 该接口实际可用的完整模型 ID |
| 请求 JSON 输出模式 | 默认开启；接口不支持该参数时关闭 |

例如，填写 `https://api.example.com/v1` 后，扩展请求的地址为 `https://api.example.com/v1/chat/completions`。也可直接填写以 `/chat/completions` 结尾的完整地址。这只是占位示例，请替换为服务商的实际地址，不要填写官网首页或其他协议的原生接口。

在 **沉浸式翻译 API** 中，保留 **沿用实时字幕 API** 即可共用上述配置；如需独立调用，选择 **OpenAI-compatible API**，并填写另一组密钥、地址和模型。

最后点击 **保存设置**。扩展不附带 API Key，接口调用费用由你使用的服务商按其规则收取。

### 3. 开始翻译

**YouTube：** 打开带有英文字幕的视频，确保弹窗中的 **启用视频实时翻译** 已开启。扩展读取字幕轨道，译文生成后逐步显示双语字幕。拖动字幕文字即可调整位置。

**Google Drive：** 打开提供转写稿的视频。扩展会短暂打开转写面板，读取带时间戳的文本后恢复面板，并在内嵌播放器中显示双语字幕。

**普通网页：** 打开包含英文正文的网页，点击右侧悬浮翻译按钮。译文显示在原文下方，优先处理当前视口附近的内容。翻译完成后，再次点击按钮可隐藏或显示译文；上下拖动按钮可调整位置。

## 字幕设置

| 设置项 | 行为与默认值 |
| --- | --- |
| 字幕翻译范围 | 默认省 token 模式；整片模式也会先处理播放位置附近，再处理其余部分 |
| 预翻译时长 | 默认未来 2 分钟；省 token 模式可选 1、2、3 分钟 |
| LLM 智能断句 | 默认开启；翻译前将相邻字幕碎片组合成完整句子 |
| AI ASR 纠错 | 默认开启；让模型修正已有字幕文本中明显的识别错误 |
| 专业术语原文 | 默认开启；在译文中显示类似 `翻译 (Translation)` 的术语对照 |
| 源语言 / 目标语言 | 默认英语 → 简体中文，也可选择繁体中文 |
| 字幕大小 | 默认 `1.00×`；范围 `0.30×–3.00×`，步长 `0.05×` |
| 字幕开关 | 默认开启；自定义字幕叠加层生效时隐藏原生字幕 |

手机上字幕偏大时，可尝试 `0.50×–0.65×` 并保存。调整字号不会重新翻译。LLM 智能断句会调用字幕 API，可能产生额外请求；关闭后使用本地字幕合并逻辑。

## 缓存与请求行为

字幕译文、已准备的字幕片段和网页译文都保存在 `chrome.storage.local` 中。

- 刷新页面后优先复用匹配的缓存，只请求缺失文本。完全命中缓存的内容不需要再次请求翻译。
- 更换模型、接口、语言或相关字幕处理设置，可能需要重新翻译；切换字幕翻译范围或预翻译时长会保留已有缓存进度。
- 跳转进度或关闭字幕会调整尚未发送的任务；已经发送的请求仍可能完成并产生费用。
- 网页标签页进入后台后暂停发送新的翻译批次，返回时继续待处理任务。
- 网页翻译等待期间会定期读取缓存，即使原响应通道卡住，也能取回已完成的译文。发生结果不明的超时或消息通道中断后，前台页面最多自动检查 12 次晚到结果，每次间隔 5 秒，不自动重发可能已计费的请求。切回标签页时也会检查缓存。已完成的译文保留；必要时可点击翻译按钮手动继续缺失内容。
- **清空翻译缓存** 会清理字幕和网页译文缓存，之后翻译可能再次调用 API。缓存容量有限，旧记录可能被淘汰。

已有准备好的字幕时间线时，刷新不会强制重新抓取原始字幕。如果视频字幕已经更新，可清空翻译缓存后重新加载视频。

## 浏览器支持与更新

仓库同时包含 Chrome 的 service worker 后台配置与 Firefox 的后台脚本配置。Manifest 声明的最低版本为 Firefox 桌面版 **140+**、Firefox for Android **142+**。

Android 上使用 Firefox 网页版视频和经过 Mozilla 签名的扩展包；仓库源码文件夹并不是可直接安装的签名包。触摸拖动和后台恢复已有自动化测试覆盖，但这不等于所有设备、网站都经过实测。YouTube 原生 App 不在扩展的作用范围内。

更新以源码加载的扩展：

1. 更新本地源码；通过 Git 克隆的仓库可执行 `git pull`。
2. 在浏览器扩展管理页重新加载 AuraTranslate。
3. 刷新已有的视频和网页标签页。

签名安装的扩展需要安装更新后的签名包，仅拉取 GitHub 源码不会更新该安装。常规更新无需清空缓存。

## 隐私与权限

| 权限 / 数据 | 用途 |
| --- | --- |
| `storage` | 在本地保存 API 设置、翻译缓存、字幕位置和悬浮按钮位置 |
| HTTP / HTTPS 网站访问权限 | 读取支持的页面内容、显示译文，以及调用配置的 API，包括本地接口 |
| YouTube / Drive 页面访问 | 读取字幕元数据或转写文本，在播放器中显示字幕 |

翻译时，待处理的字幕或网页文本会发送到你配置的 API 地址；LLM 智能断句也会向该接口发送字幕文本。API Key 保存在浏览器扩展的本地存储中，项目没有额外加密存储密钥；密码输入框只负责遮挡屏幕上的显示内容。

当前源码没有独立的 AuraTranslate 账号服务或统计上报接口。发送给 API 服务商的文本，由该服务商按其数据政策处理。

## 常见问题

| 问题 | 排查方法 |
| --- | --- |
| 视频没有双语字幕 | 检查弹窗开关，确认 YouTube 有英文字幕或 Drive 提供转写稿。没有可用文本的视频无法由本扩展转写。 |
| API Key / 模型报错 | 检查密钥、完整模型 ID、Chat Completions 基础地址，以及账号是否有该模型的调用权限。 |
| JSON 输出报错 | 如果接口拒绝 JSON 模式参数，关闭该选项；如果支持，开启后通常更有利于模型返回结构化结果。 |
| 翻译较慢 | 首次出字幕受字幕抓取和接口延迟影响。可使用省 token 模式，并缩短预翻译时长以减少待处理内容。 |
| 网页翻译超时 | 停留在页面等待自动恢复，或切回标签页检查缓存；仍有缺失时点击翻译按钮手动继续。更新源码后需重新加载扩展并刷新网页，无需清空缓存。 |
| 网页部分内容没有翻译 | 表单控件、代码块、装饰内容和明确排除的区域会跳过。图片、画布、嵌套框架或不支持的页面结构中的文字可能无法提取；每次最多选择 240 个文本块。 |
| 更新后扩展无法工作 | 重新加载扩展，再刷新受影响的标签页。 |
| 原视频字幕变了，仍显示旧内容 | 在设置中清空翻译缓存，然后刷新视频。 |

反馈问题时，请附上浏览器及版本、页面地址、复现步骤和错误文本。截图或日志中请移除 API Key 等私人信息。

## 开发

扩展使用原生 JavaScript、HTML 和 CSS，测试使用 Node 内置测试运行器与 jsdom。Node.js 版本需符合锁定的 jsdom 依赖要求：`^22.22.2`、`^24.15.0` 或 `>=26.0.0`。

```sh
npm ci
npm test
```

Windows 下如果 PowerShell 阻止执行 `npm.ps1`，改用 `npm.cmd ci` 和 `npm.cmd test`。

测试覆盖字幕解析、配置保存、智能断句、缓存、网页提取与格式保留、标签页生命周期恢复、消息超时和字幕拖动。测试模拟浏览器行为，真实 API 与设备验证需另外进行。

```text
manifest.json       扩展信息、权限与入口
src/
  background.js     API 请求、缓存持久化与消息分发
  content.js        视频字幕、播放调度与字幕叠加层
  drive.js          Drive 转写稿读取与内嵌播放器通信
  immersive.js      网页提取、翻译调度与译文显示
  shared.js         默认设置、字幕工具与 API 配置
  page-bridge.js    YouTube 播放器元数据与字幕请求桥接
  overlay.css       字幕样式
  immersive.css     网页翻译样式
options/            设置界面
popup/              字幕开关与设置入口
test/               自动化测试与测试数据
```
